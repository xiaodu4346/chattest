# ChatTest

ChatTest 是一个用 C++ 和 Qt 从零学习并实现的简化版即时通讯软件。

这个项目的重点不只是“做出一个能跑的软件”，更重要的是通过一步一步实现功能，理解：

- Qt 如何绘制界面和组织窗口、控件、信号槽
- C++ 项目如何拆分文件、类和模块
- 客户端和服务器如何通过网络通信
- 登录、发消息、发图片等功能背后的基本设计
- 一个软件项目如何规划、记录、测试和逐步迭代

## 项目记忆系统

我们会用 `memory/` 目录保存长期上下文：

- `memory/project_brief.md`：项目目标、范围和技术路线
- `memory/learning_log.md`：每一步学了什么、做了什么
- `memory/decisions.md`：重要技术选择和原因
- `memory/next_steps.md`：当前任务、下一步和待确认问题

每完成一个阶段，我们都会更新这些文件，让这个仓库自己记住我们的学习过程。
