# 下一步任务

## 当前任务

项目刚刚启动，仓库已经加入记忆系统，并确认 Qt 环境可用。

## 下一步

建议先不要急着写聊天功能，而是按下面顺序来：

1. 使用 `scripts\run.ps1` 在本机运行第一个 Qt 窗口
2. 讲解第一个 Qt 程序的每一行代码
3. 把 `QLabel` 示例改成真正的登录窗口
4. 学习 Qt 信号槽，让登录按钮点击有反应
5. 再进入聊天窗口 UI
6. 最后开始网络通信

## 需要确认的问题

- IDE 已确定使用 VS Code。
- Qt 已安装：`C:\Qt\6.11.1\mingw_64`
- 当前 Qt 套件为 MinGW 版，不是 MSVC 版。
- 你的系统看起来是 Windows，我们后续会默认按 Windows 教程来写。
