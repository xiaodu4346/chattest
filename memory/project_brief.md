# 项目简介

## 项目名称

ChatTest

## 项目目标

用 C++ 和 Qt 从零实现一个简化版“微信式”聊天软件。它不是商业级产品，而是一个学习型项目，目标是帮助开发者系统理解桌面应用、UI、网络通信、客户端/服务器架构和基础工程实践。

## 目标功能

第一阶段先做最小可用版本：

- 用户登录
- 聊天窗口
- 发送文本消息
- 接收文本消息
- 显示聊天记录

后续逐步加入：

- 发送图片
- 用户注册
- 好友列表
- 群聊雏形
- 本地聊天记录保存
- 简单服务器
- 更像真实软件的界面优化

## 技术方向

- 语言：C++
- UI 框架：Qt Widgets
- 构建系统：CMake
- 网络通信：先使用 Qt 的 `QTcpSocket` / `QTcpServer`
- 数据格式：先使用简单 JSON
- 数据存储：先从内存数据开始，后续引入 SQLite

## 学习原则

- 每一步都要先理解思路，再写代码
- 功能从小到大，避免一开始追求完整复杂系统
- 每个阶段都保留可运行版本
- 不跳过基础概念，比如类、对象、信号槽、事件循环、TCP、JSON、UI 布局
- 重要决策写入 `memory/decisions.md`
- 学习过程写入 `memory/learning_log.md`
